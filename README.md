# Lazeez Kebabs & Açaí — website

Live: https://karankirtisharma.github.io/clientkebabsite/

Static, deploy-ready build of the one-page site for Lazeez Kebabs & Açaí (Shop 4/386 Main Road, Wellington Point QLD): scroll-driven 3D (Three.js), GSAP + ScrollTrigger animations and Lenis smooth scrolling.

This repository contains the **built output only** — no build step is needed to serve it. It is generated by `deploy/build.py` in the project workspace:

```
python -I deploy/build.py --site-url https://karankirtisharma.github.io --base-path /clientkebabsite --out deploy/dist-pages
```

For a custom domain at the root, build without `--base-path` (and with `--site-url https://your-domain`); `_headers` / `vercel.json` then carry the cache rules for Netlify, Cloudflare Pages or Vercel.
