# Lazeez Kebabs & Açaí — website

- **Live (primary):** https://lazeezkebabs.vercel.app/ — deployed by Vercel from the `main` branch
- **Mirror:** https://karankirtisharma.github.io/clientkebabsite/ — GitHub Pages, from the `gh-pages` branch

Static, deploy-ready build of the one-page site for Lazeez Kebabs & Açaí (Shop 4/386 Main Road, Wellington Point QLD): scroll-driven 3D (Three.js), GSAP + ScrollTrigger animations and Lenis smooth scrolling.

This repository holds **built output only** — no build step is needed. Both branches are generated by `deploy/build.py` in the project workspace:

```
# main  (served at the site root, e.g. Vercel or a custom domain)
python -I deploy/build.py --site-url https://lazeezkebabs.vercel.app

# gh-pages  (served from the /clientkebabsite/ sub-folder)
python -I deploy/build.py --site-url https://karankirtisharma.github.io --base-path /clientkebabsite --canonical-url https://lazeezkebabs.vercel.app --out deploy/dist-pages
```

Both copies point search engines and share previews at the primary (Vercel) URL. `vercel.json` / `_headers` carry the cache rules (code and fonts 1 year, images 1 day).
